# Floffy Buddy · 플로피버디

`크롬으로 실행.bat`을 더블클릭하면 Chrome에서 바로 플레이할 수 있습니다. 또는 `index.html`을 Chrome으로 여세요. 별도 설치나 빌드가 필요하지 않습니다.

- 스페이스바 / 위쪽 화살표 / 클릭 / 터치: 날갯짓
- P: 일시정지 및 계속하기
- R: 새 게임
- 오른쪽 위 소리 버튼: 효과음 켜기/끄기

파이프 사이를 통과하면 1점을 얻습니다. 파이프, 바닥 또는 천장에 닿으면 게임이 끝납니다. 점수가 높아지면 속도가 빨라지고 통로가 조금 좁아집니다. 최고 점수는 브라우저에 저장됩니다. 다른 창으로 이동하면 자동으로 일시정지합니다.

HTML, CSS, Canvas와 Web Audio로 제작되었습니다. 인터넷이 없어도 플레이할 수 있으며, 온라인에서는 Google Fonts 글꼴을 불러옵니다.

플로피 옷장에서 무지개 일곱 색, 분홍, 민트, 무지개 무늬까지 총 10가지를 선택할 수 있습니다. 선택한 색은 자동 저장되며, 플레이 중 색을 바꾸면 잠시 멈춥니다.

파이프 통로의 너비는 매번 무작위로 바뀝니다. 초반에는 145~215px, 25점부터는 125~190px 범위로 좁아집니다. 연속된 통로 중심의 높이 차이는 최대 100px로 제한해 급격한 이동을 줄였습니다.
